# Exercícios de MATLAB

Compilação de 10 exercícios práticos em MATLAB, do básico ao intermédio, com aplicação real.

## Requisitos

- MATLAB R2018b **ou** Octave 7+

## Como usar

1. Clonar o repositório:
   ```bash
   git clone https://github.com/danieldluis/exercicios_matlab
   ``` 
2. Abrir o MATLAB (ou Octave) e mudar para a pasta do repositório.
3. Executar cada script `.m` na ordem recomendada.

## Ordem recomendada

| Fase | Ficheiros | Tópico |
|------|-----------|--------|
| 1 | `conversao_temperaturas.m`, `media_ponderada.m`, `populacao_logistica.m` | Vetores, matrizes, plot |
| 2 | `aproximacao_euler.m`, `velocidade_media.m`, `raizes_quadraticas.m` | Laços, funções |
| 3 | `analise_vendas.m`, `juros_compostos.m`, `temperaturas_diarias.m`, `sistema_linear.m` | Análise de dados, eficiência |
